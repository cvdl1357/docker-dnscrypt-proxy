# Security Policy

## Supported Versions

Only the latest release of this container image receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this repository or container build, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please submit a report via [GitHub Private Vulnerability Reporting](https://github.com/cvdl1357/docker-dnscrypt-proxy/security/advisories/new).

### Response Process

* **Acknowledgment:** Reports will be acknowledged within 72 hours.
* **Assessment:** Vulnerabilities will be evaluated against upstream `dnscrypt-proxy` and `Alpine Linux` baseline updates.
* **Fix & Release:** Valid fixes will be committed directly to `main` and a new container image will be pushed to GHCR.
